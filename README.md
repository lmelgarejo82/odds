# Laboratorio Consenso 2.5

Análisis experimental e independiente de consenso Forebet + Statarea para Más/Menos 2.5.

El Bloque 1 inicializa arquitectura, modelo, contratos, pruebas e interfaz. Los bloques 2 y 3 incorporan capturas controladas independientes de Forebet y Statarea para `2026-07-21`, con evidencia inmutable e idempotencia. Las columnas Statarea se conservan raw y no se interpretan como señales. No calcula matching, consenso, rankings ni resultados.

> Prioridad estimada para apoyo de decisiones. No representa certeza, garantía ni apuestas ejecutadas.
