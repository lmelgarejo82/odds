Análisis experimental e independiente de consenso Forebet + Statarea para Más/Menos 2.5.

El Bloque 1 inicializa arquitectura, modelo, contratos, pruebas e interfaz. El Bloque 2 incorpora una única captura controlada de Forebet O/U 2.5 para `2026-07-21`, con evidencia inmutable e idempotencia. No calcula consenso, rankings ni resultados.
